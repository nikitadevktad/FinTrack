# FinTrack

FinTrack это Android-приложение для учёта личных финансов в RUB. В первой версии не планируются сервер, регистрация и банковские интеграции. Операции будут вводиться вручную и храниться локально.

## Текущий статус

Создан базовый Android-проект с модулем `app`, Kotlin, Jetpack Compose и Material 3. Сейчас в приложении отображается стартовый шаблонный экран. Учёт операций, локальное хранилище, Room, Coroutines и Flow ещё не реализованы.

## Планируемые возможности

- Добавление доходов и расходов
- Категоризация операций
- Редактирование и удаление операций
- История и фильтрация по периоду, типу и категории
- Сводка доходов и расходов
- Графики по категориям и периодам

## Планируемый стек

- Kotlin
- Jetpack Compose
- Material 3
- Room
- Coroutines
- Flow

## Разработка

Сначала реализуется минимальная модель операций и локальное хранение, затем сценарии добавления и просмотра, после этого фильтры, сводки и графики. Пока используется один модуль `app`. Пакеты создаются по мере появления кода. Пустые классы и файлы-заглушки не добавляются.

Архитектурный план приведён в [docs/architecture.md](docs/architecture.md).
