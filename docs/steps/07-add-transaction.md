# Шаг 07. Добавление операции и история

На экране «История» появилась кнопка «Добавить операцию». Она открывает форму через существующий `NavHost`. В форме выбираются тип, сумма, категория и необязательная заметка. Дата операции берётся из текущей локальной даты.

`AddTransactionViewModel` загружает категории из `CategoryRepository`, оставляет только категории выбранного типа и сбрасывает несовместимый выбор. Сумма разбирается без `Double`. Целая часть и копейки преобразуются в `Long`. Поддерживаются точка или запятая и не более двух цифр после разделителя.

После проверки `AddTransactionViewModel` передаёт доменную операцию в `TransactionRepository`. Репозиторий записывает её через Room в таблицу `transactions`. Пока идёт запись, повторное сохранение недоступно. Ошибка не закрывает форму и не очищает поля.

`HistoryViewModel` получает поток операций от `TransactionRepository`, сопоставляет их с загруженными категориями и публикует элементы истории. Экран собирает состояние с учётом жизненного цикла. Room отправляет обновлённый список в `Flow` после вставки, поэтому сохранённая операция появляется в истории без ручного обновления.
