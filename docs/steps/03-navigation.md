# Шаг 03. Навигация

На этом шаге в приложении добавлены основные экраны и нижняя навигация на Navigation Compose.

## Состав интерфейса

`MainActivity` включает тему `FinTrackTheme` и передаёт управление в `FinTrackApp`.

`FinTrackApp` создаёт общий `Scaffold` с нижней панелью `NavigationBar`. Он также создаёт `NavHost`, который сопоставляет маршруты с независимыми экранами.

В `NavHost` определены три маршрута.

- `overview` для начального экрана «Обзор»
- `history` для экрана «История»
- `analytics` для экрана «Аналитика»

Экраны находятся в пакетах `presentation/overview`, `presentation/history` и `presentation/analytics`. Каждый экран принимает `Modifier` и не зависит от `NavController`.

## Поведение вкладок

Начальный маршрут это «Обзор». Выбранная вкладка определяется по текущему маршруту `NavController`.

При выборе вкладки включается `launchSingleTop`, поэтому повторное нажатие не добавляет копию экрана в стек. При переходе состояние предыдущей вкладки сохраняется, а при возврате восстанавливается средствами Navigation Compose.

Нажатие системной кнопки «Назад» на вкладках «История» и «Аналитика» возвращает на «Обзор». На начальной вкладке используется стандартное поведение Android.

## Пустые состояния

- «Обзор» показывает текст «Добавьте первую операцию, чтобы увидеть сводку»
- «История» показывает текст «Операций пока нет»
- «Аналитика» показывает текст «Аналитика появится после добавления операций»

Все строки находятся в ресурсах. Для вкладок добавлены компактные векторные иконки из ресурсов приложения, поэтому отдельная библиотека иконок не требуется.
