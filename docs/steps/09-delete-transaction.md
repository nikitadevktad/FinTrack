# Шаг 09. Удаление операции

При редактировании загруженной операции доступна кнопка удаления. Перед удалением форма показывает подтверждение с действиями «Отмена» и «Удалить». Отмена и закрытие диалога сохраняют запись и данные, введённые в форме.

`TransactionDao` удаляет строку по идентификатору и возвращает число удалённых строк. Репозиторий преобразует этот результат в признак успеха. Удаляется только операция, категории и остальные записи не изменяются.

Во время удаления нельзя повторно удалить операцию или сохранить форму. При ошибке форма остаётся открытой. Если запись уже отсутствует, пользователь видит сообщение и может вернуться в историю. После успешного удаления форма закрывается, а история обновляется через существующий `Flow` Room. Для последней удалённой операции отображается прежнее пустое состояние.
