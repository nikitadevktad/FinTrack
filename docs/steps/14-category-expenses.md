# Шаг 14. Расходы по категориям

Под сводкой на вкладке аналитики показана разбивка расходов по категориям для выбранного периода. Room соединяет операции с категориями, оставляет только категории типа `EXPENSE` и группирует суммы в копейках по идентификатору категории. Категории упорядочены по убыванию суммы, затем по названию и идентификатору.

Границы периода совпадают со сводкой. Начальная дата включается, а конечная дата включается через сравнение с днём после неё. Поток Room обновляет разбивку после добавления, изменения или удаления операции. При выборе другого периода `flatMapLatest` отменяет прежние запросы.

Доля рассчитывается из сумм полученного списка категорий. Для вычисления используется `BigDecimal`, поэтому умножение на 100 не переполняет `Long`. Процент округляется до двух знаков, поэтому итог отображаемых долей может немного отличаться от 100 процентов.

При отсутствии расходов выводится отдельное сообщение. Загрузка и ошибка разбивки также отображаются отдельно от состояния сводки.
