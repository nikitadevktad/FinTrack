# Шаг 12. Фильтры типа и категории в истории

История объединяет период, тип и категорию в одном состоянии фильтров. Условия применяются одновременно. Пустой параметр периода, типа или категории отключает соответствующее условие в запросе Room.

Тип операции определяется по связанной категории. После выбора типа список категорий содержит только подходящие варианты. Если выбранная категория не относится к новому типу, сбрасывается только категория, а период сохраняется.

Запрос Room возвращает `Flow` и сохраняет сортировку по дате и идентификатору. `flatMapLatest` переключает его при изменении фильтров, поэтому история обновляется после добавления, изменения или удаления операции. Действие сброса возвращает все операции.
