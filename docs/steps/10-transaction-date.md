# Шаг 10. Дата операции

В форме добавления и редактирования есть поле даты операции. Новая форма получает текущую локальную дату. При редактировании отображается дата из сохранённой операции.

Поле открывает Material 3 DatePickerDialog. Выбранная в календаре дата попадает в состояние формы только после подтверждения. Закрытие или отмена диалога оставляет прежнюю дату без изменений.

Форма хранит дату как LocalDate. DatePicker возвращает миллисекунды UTC, поэтому перед обновлением состояния они преобразуются в календарную дату в UTC. Это исключает смещение даты из-за часового пояса.

При сохранении новая дата передаётся в Transaction. Репозиторий сохраняет её как epochDay. Редактирование использует прежний идентификатор операции. Запрос Room сортирует операции по dateEpochDay, а Flow передаёт истории обновлённый и пересортированный список.
